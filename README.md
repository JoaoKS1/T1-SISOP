# T1-SISOP
## Comandos terminal:
`new <nomePrograma>` - Para criar um novo processo, seguindo a lista. Coloca processo em lista de processos prontos. Retorna identificador único do processo.

`rm <id>` - Retira processo id do sistema, tenha executado ou não

`ps` - Lista todos os processos existentes

`dump <ps>` - Lista o conteúdo do PCB e o conteúdo da memória do processo com id

`dumpM <inicio, fim>` - Lista memória entre posição inicio e fim 

`exec <id>` - executa processo com id informado. Se não houver, retorna erro

`traceOn` - Liga modo de execução em que CPU printa cada instrução executada

`traceOff` - Desliga modo acima

`exit` - Sai do sistema
